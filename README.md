# AI Safety — құрылыс алаңындағы қауіпсіздік көмекшісі

«Қауіпсіз құрылыс» командасы, 8-топ · «Жасанды интеллект негіздері» емтихандық жобасы.

Сайт кез келген браузерде (компьютер, iPhone, Android) **тіркелусіз** ашылады. Оны телефонға қосымша ретінде де орнатуға болады (PWA). ЖИ бөлігі Google Gemini API арқылы жұмыс істейді.

## Функциялар

1. **Сұрақ қою.** Құрылыс қауіпсіздігі бойынша чат. Жауапта ҚР құжатының бабы немесе тармағы көрсетіледі.
2. **Фото тексеру.** Алаң фотосынан қауіптерді табады, әр қауіпке түзету шарасын ұсынады.
3. **Чек-лист.** Жұмыс түріне қарай тексеру тізімін жасайды, оны PDF ретінде жүктеуге болады.
4. **Білім базасы.** ЖИ жауап беру үшін қолданатын құжаттар. Тармақтарды кілт сөз бойынша іздеуге болады.

## Жүйенің жұмыс істеуі

```
Пайдаланушы (браузер / телефон)
   → public/index.html: сұрақ, фото немесе жұмыс түрі
   → kb.json ішінен сәйкес баптар мен тармақтарды іздеу (браузерде)
   → POST /api/ask: промпт + табылған үзінділер + фото
   → api/ask.js (сервер): кілт тек осында сақталады
   → Google Gemini API (gemini-3.6-flash, қосалқы модель — gemini-3.5-flash-lite)
   → жауап: мәтін немесе JSON → нәтиже экранда, үзінділер сілтемесімен
```

Білім базасы (`public/kb.json`):
- ҚР Еңбек кодексі: 22, 23, 180–188, 201-баптар;
- «Жоғары вольтты жабдықтардың қауіпсіздік талаптары» техникалық регламенті (№481 бұйрық, 49 тармақ);
- ДСМ-49, №1019, №927 бұйрықтарының қысқаша мазмұны;
- жалпы құрылыс тәжірибесі.

Мәтіндер adilet.zan.kz сайтынан 25.11.2026 алынды.

## Ең жылдам жол: компьютерде бірден ашу

1. Архивті ашыңыз (zip ішінен шығарып алыңыз: оң жақ батырма → «Извлечь все» / «Extract all»).
2. `public` папкасындағы `index.html` файлын екі рет басыңыз. Сайт браузерде ашылады.
3. Алғаш ашқанда «Gemini API кілті» терезесі шығады. Төмендегі 1-қадам бойынша тегін кілт алып, сол терезеге қойыңыз.

Кілт тек сол браузерде сақталады. Бұл тәсіл компьютерде тексеруге және демонстрация жасауға жарайды. Басқа адамдар телефоннан сілтеме арқылы ашуы үшін 2-қадамды орындаңыз.

## 1-қадам. Gemini API кілтін алу (тегін)

1. https://aistudio.google.com/apikey сайтына Google аккаунтымен кіріңіз. Ол үшін жасыңыз 18-ден асуы керек.
2. **Create API key** батырмасын басып, кілтті көшіріп алыңыз.
3. Кілтті ешкімге жібермеңіз және кодқа жазбаңыз. Ол тек хостингтің баптауларында сақталады.

## 2-қадам. Интернетке жариялау (Vercel, тегін)

1. GitHub-та жаңа репозиторий жасаңыз (мысалы, `ai-safety`). Осы папканың **ішіндегі** барлық файлды жүктеңіз: `api/`, `public/`, `package.json`, `vercel.json` және басқалары.
2. https://vercel.com сайтына GitHub аккаунтымен кіріңіз → **Add New → Project** → репозиторийді таңдаңыз.
3. **Environment Variables** бөліміне мынаны қосыңыз:
   - `GEMINI_API_KEY` = 1-қадамда алған кілтіңіз.
4. **Deploy** батырмасын басыңыз. 1–2 минуттан кейін `https://ai-safety-xxxx.vercel.app` түріндегі сілтеме дайын болады.
5. Сілтемені оқытушыға және тестілеушілерге жіберіңіз. Тіркелу керек емес.

Кодты өзгертсеңіз, GitHub-қа жүктеген сайын Vercel сайтты өзі жаңартады.

## Компьютерде тексеру (міндетті емес)

Node.js 20 немесе одан жаңа нұсқасы керек.

```
cp .env.example .env              # .env ішіне GEMINI_API_KEY жазыңыз
node server.js                    # http://localhost:3000
```

## Телефонға орнату

- **Android (Chrome):** сайтты ашыңыз → «Қосымша ретінде орнату» батырмасы немесе ⋮ → «Басты экранға қосу».
- **iPhone (Safari):** сайтты ашыңыз → «Бөлісу» → «На экран Домой».

## Баптаулар (Environment Variables)

| Айнымалы | Мәні |
|---|---|
| `GEMINI_API_KEY` | Міндетті. Google AI Studio кілті |
| `GEMINI_MODEL` | Міндетті емес. Модельдер тізімі үтір арқылы, әдепкі: `gemini-3.6-flash,gemini-3.5-flash-lite` |
| `RATE_PER_MIN` | Міндетті емес. Бір IP-ден минутына сұрау саны, әдепкі: 12 |

Google модель атауларын жиі жаңартып отырады. Сайт «модель табылмады» десе, https://ai.google.dev/gemini-api/docs/models бетінен жаңа атауын тауып, `GEMINI_MODEL` айнымалысына жазыңыз.

## Шектеулер

- Gemini-дің тегін деңгейінде минуттық және күндік лимит бар. Лимит бітсе, сайт «бір минуттан кейін қайта көріңіз» деп хабарлайды.
- Тегін деңгейде Google сұрауларды өз модельдерін жақсарту үшін пайдалануы мүмкін. Сондықтан сайтқа дербес деректер мен адамдардың беті анық көрінетін фотоларды жүктемеңіз.
- ЖИ қателесуі мүмкін. Сайт ресми нұсқаулықты және еңбек қауіпсіздігі маманының шешімін алмастырмайды.
